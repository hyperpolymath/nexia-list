= nexia-list — Quick Start for Users
:toc:
:toclevels: 2

== What is nexia-list?

Nexia-List is a local-first personal knowledge management tool: notes on a spatial
canvas with bidirectional links and (planned) intelligent agents. It runs in
your browser — your data stays on your device as human-readable JSON. See
link:README.adoc[README.adoc] for the full pitch.

== Prerequisites

Before you begin, ensure you have:

* **just** — task runner (https://github.com/casey/just[install guide])
* **Deno 2.x** — https://deno.land/[install guide]
* **Rust stable** — https://www.rust-lang.org/tools/install[install guide]
  (needed to build the core; `just setup` adds the WASM target)
* A modern web browser

== Install

[source,bash]
----
# Clone and set up
git clone https://github.com/hyperpolymath/nexia-list.git
cd nexia-list
just setup
----

The setup recipe will:

* Install JS dependencies via Deno (no npm required)
* Add the `wasm32-unknown-unknown` Rust target for the WASM core

== First Run

[source,bash]
----
just run
----

Then open http://localhost:5173 in your browser.

NOTE: Nexia-List is pre-release (v0.1, in active development). You can create,
edit, delete, and search notes; the spatial canvas supports pan/zoom and
double-click note creation. Drag-and-drop and a desktop app are not available
yet.

== Self-Diagnostic

If something isn't working:

[source,bash]
----
just doctor
----

This checks that the required tools (just, git, deno, cargo) are available
and suggests fixes if not.

== Get Help

* **Guided tour**: `just tour`
* **Report a problem**: `just help-me` (pre-fills diagnostic context)
* **Wiki**: https://github.com/hyperpolymath/nexia-list/wiki

== Uninstall

Nexia-List makes no system-wide changes. To remove it, delete the cloned
directory. Your notebooks are plain JSON files — export/download them first
if you want to keep them (browser data lives in IndexedDB for the site until
you clear it).
