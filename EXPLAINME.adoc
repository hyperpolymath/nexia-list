Nexia-List is an open-source, local-first knowledge management tool inspired by https://www.eastgate.com/Tinderbox/[Tinderbox].
____

== Technology Choices

[cols="1,2"]
|===
| Technology | Learn More

| **Bun 1.3+** (only JS toolchain) | https://bun.sh
| **ReScript 11** (TEA-style UI on @rescript/react) | https://rescript-lang.org
| **Rust** (core engine, compiled to WASM via wasm-bindgen) | https://www.rust-lang.org
| **Bun bundler** | https://bun.sh/docs/bundler
|===

== File Map

[cols="1,2"]
|===
| Path | What's There

| `core/` | Rust core: Note/Notebook, backlinks, substring search, JSON storage
| `ui/` | ReScript TEA-style UI (Model/Msg/Update/View + DOM bindings)
| `scripts/` | Bun build/dev scripts
| `web/` | Browser entry + bundle output (`dist/`)
| `desktop/` | Optional Gossamer shell (external sibling checkout; not built in CI)
| `docs/adr/` | Architecture decision records (web-first WASM, Bun-only)
| `tests/` | Cross-cutting test suite
|===
