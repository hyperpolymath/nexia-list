== LLM Warmup — nexia-list (Developer)

=== What is nexia-list?

See README.adoc for overview.

=== Key Commands

* `+just setup+` — set up development environment
* `+just build+` — build the project
* `+just test+` — run tests
* `+just doctor+` — diagnose issues
* `+just maps+` — regenerate the text view of committed notebooks (`+just maps check+` verifies)
* `+just run+` — start the dev server (http://localhost:5173)
